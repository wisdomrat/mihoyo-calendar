## 结构区域

| 编号 | 名称 | 定义 |
| --- | --- | --- |
| S1 | 舞台容器 | 左侧圆角立绘舞台的边界、裁切与表面。 |
| S2 | 立绘主体区 | 角色图片本身、裁切位置和主体视觉焦点。 |
| S3 | 舞台顶部上下文 | 当前角色、游戏/地区、事件信号等轻量信息。 |
| S4 | 角色信息区 | 角色名、英文名、归属、日期、详情入口。 |
| S5 | 舞台边界 | 舞台与页面背景的轻边界，不是发光卡片。 |
| G1 | 双栏间隙 | 左右容器之间的留白、细分隔线和共享光场过渡。 |
| C0 | 月历表面 | 右侧半透明深色面板本身，与全局背景保持色温连续。 |
| C1 | 月份标题与上下文 | 月份、事件统计、当前筛选的主摘要。 |
| C2 | 月份操作与语义控制 | 翻月、今天、月/周、生日/实装等高频操作。 |
| C3 | 星期标题带 | 7 列的星期标签和周末轻强调。 |
| C4 | 7 列日期网格 | 日期数字、补位日期和固定几何轨道。 |
| C5 | 事件标记层 | 生日/实装事件点、细环和少量状态标记。 |
| C6 | 头像密度层 | 单头像、2–3 个堆叠、4+ 头像加 `+N`。 |
| C7 | 今天/选中态 | 浅色药丸或局部标记，不整格换材质。 |
| C8 | 图例、筛选与摘要 | 颜色图例、筛选摘要、当天信息条。 |
| T1 | 品牌锁定区 | 中文产品名和简短副标题。 |
| T2 | 中央裸文字导航 | 无轮廓的真实导航文字，融入背景。 |
| T3 | 顶部状态摘要 | 月份、事件数和当前上下文的弱信息。 |
| T4 | 今天入口 | 回到当前日期的单一明确动作。 |
| T5 | 日历核心操作 | 月份、视图和事件语义的控件层。 |
| T6 | 筛选状态摘要 | 筛选面板关闭后仍可见的当前状态。 |
| M1 | 移动顶部带 | 移动端有限高度的品牌与月份信息。 |
| M2 | 移动角色舞台 | 移动端的主视觉角色区域。 |
| M3 | 移动 7 列月历 | 可快速扫描的移动月视图。 |
| M4 | 下一事件/详情入口 | 月历之后的当天或下一事件信息块。 |

## 视觉图层

| 编号 | 名称 | 定义 |
| --- | --- | --- |
| L1 | 角色对应主光晕 | 依主题和角色舞台位置变化的主光源；须弥示例位于左上。 |
| L2 | 全局色温渐变 | 页面从深靛/深青绿向紫色的连续背景过渡。 |
| L3 | 立绘垂直压暗 | 立绘从上方较透明到下方较深的可读性渐变。 |
| L4 | 可读性落点 | 角色标题和日期所在的稳定暗部区域。 |
| L5 | 角色局部强调 | 边框、头像环、事件点和少量标签的角色/地区色。 |

## 独立场景

| 编号 | 名称 | 定义 |
| --- | --- | --- |
| H1 | 全屏 Hero 场景边界 | 从左侧舞台进入的独立全屏状态，不是默认首页。 |
| H2 | Hero 增强层 | 仅在 Hero 内增强背景和光晕，不永久改工作区主题。 |
| H3 | Hero 文字可读区 | Hero 中承载角色名、日期和归属的压暗区域。 |
| H4 | Hero 关闭后恢复 | 关闭时恢复月份、筛选、角色和主题状态。 |

## 讨论规则

- “打光”拆成 `L1 主光晕`、`L2 全局渐变`、`L3 立绘压暗`、`L4 可读性落点`。
- “中间控件”拆成 `T2 中央裸文字导航` 或 `T5 日历核心操作`，不得混称。
- “头像效果”属于 `C6 头像密度层`，头像不能改变 `C4` 网格几何。
- “主题变色”优先描述 `L1/L2/L5` 的变化，不描述成“整页换皮”。
