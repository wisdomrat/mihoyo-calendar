# R1 反馈问题记录

提交时间：2024-09-13

## 问题清单

### 1. 日历网格角色头像过小
**描述**：日历下的C3（7列日期网格）里面的角色头像明显偏小
**当前状态**：`--v2-avatar-size: 24px`
**需要**：增大头像尺寸，参考原型设计

### 2. 角色详情弹窗位置不当
**描述**：点击头像后弹窗页面（角色详情）默认在左上角，应该居中显示
**当前状态**：弹窗位置未居中
**需要**：弹窗应该在视口中心

### 3. 舞台点击应显示沉浸式Hero页面
**描述**："左侧角色舞台"点击后应该是弹出hero主页这种沉浸感和视觉效果好的，而不是共用前面的角色详情
**当前状态**：舞台点击显示通用角色详情
**需要**：为舞台创建独立的沉浸式展示页面（Hero风格）

### 4. 舞台下方和日历下方信息重复
**描述**：
- 舞台下方显示："10月27日 · 生日 草 · 法器 · 5星"
- 日历下方显示："10月27日 · 1位角色 纳西妲"
- 内容重复且日历下方信息错位

**需要**：对比原型和计划设计，调整或移除日历下方的重复信息

### 5. 角色详情立绘显示不完整
**描述**：
- 立绘不能完整显示
- 绝区零的竖着的立绘被裁切上下部分
**需要**：参考原版设计，根据立绘尺寸动态调整角色详情窗口大小

### 6. 光场效果不明显
**描述**：
- 以纳西妲为例，初版打光视觉效果非常好（参考：`docs/calendar-redesign/candidates/candidate-GPT-01/concept-v3-GPT`）
- 当前打光效果被遮挡，看不出来
**需要**：
- 调整光场层级和透明度
- 参考初版设计恢复光场视觉效果
- 调整其他光的细节

### 7. 整体布局尺寸偏小
**描述**：目前日历区域的大小和整个页面的区域的大小感觉还是偏小
**需要**：调整布局尺寸，使其更加适合和有美感
