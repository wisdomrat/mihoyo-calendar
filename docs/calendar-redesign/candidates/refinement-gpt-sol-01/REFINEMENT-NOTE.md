# gpt-sol 受控精修说明

## 保留的 GPT 母版

保留左侧约 34% 的沉浸式角色舞台、右侧约 66% 的 7 列真实月视图、深靛黑/靛蓝中性底、大面积留白、角色立绘主角地位，以及“角色识别 > 少量状态色”的层级。游戏/地区切换只改变舞台、光晕、标签和事件点，不改变网格、日期位置或主要操作路径。移动端仍按“主角舞台 → 月历 → 下一事件/详情”纵向阅读。

## 本轮改动（5 件）

1. 将英文虚构导航改成“米哈游角色生日日历 / 角色生日与实装纪念日”，删除 INSIGHTS、COLLECTION、ORBIT 等暗示不存在页面的文字。
2. 将控件分为常驻导航（上月、下月、今天、月/周、生日/实装、搜索、筛选摘要）与统一“筛选 / 显示 / 更多”面板；面板从工作区右侧保留轨展开，不遮挡 7 列网格，点击外部、完成或 Escape 收起，关闭后摘要标签仍可见。
3. 固定三档头像密度，日期数字和星期位置不随数据跳动；图 1 同月同时展示单头像、2–3 个堆叠和 4+ 个“3 个头像 +N”。
4. 在图 2 加入“原神 / 须弥”上下文与当天角色详情卡，仅换薄荷色 token、舞台光晕和局部边线；网格和详情返回路径稳定。
5. 移动端重排为独立纵向首屏，保留 7 列月视图、筛选入口和下一事件卡，避免桌面双栏压缩或横向滚动。

## 头像密度规则

- 桌面：1 位 48–64px；2–3 位 32–38px，重叠 25–35%；4+ 位 26–30px，最多 3 个头像并显示“+N”。
- 移动：1 位 30–40px；2–3 位 24–30px 堆叠；4+ 位 18–24px 小头像 +“+N”。“+N”打开当天完整名单入口，不静默丢失角色。

## 控件分层

常驻：月份导航、今天、月/周、生日/实装、搜索、筛选摘要。展开面板：游戏多选、地区/阵营、属性、稀有度、武器/命途/特性、头像密度、立绘背景、动效、周起始日、收藏。低频：添加/编辑、JSON 导入导出、ICS、数据更新和最后更新时间。

## 文字与上下文处理

LUMEN 仅保留为品牌名也没有必要，本稿直接删除；INSIGHTS、COLLECTION 删除，不创建虚构页面。原神/须弥改变薄荷色、主角纳西妲、标签和匹配事件点；只选原神时回落到原神级主题；星穹铁道、崩坏3没有细分阵营时只用游戏级主题。正文对比度、网格尺寸、焦点环和操作含义保持稳定。

## 仍存的两个最大风险

1. 真实数据的极端密集月份可能让 4+ 头像与日期提示竞争空间，需要在实现时锁定行高并把完整名单交给当天面板。
2. 角色立绘与阵营光晕叠加时可能降低文字对比度；正式实现需以灰度检查、对比度测试和 `prefers-reduced-motion` 静态退化作为门槛。
