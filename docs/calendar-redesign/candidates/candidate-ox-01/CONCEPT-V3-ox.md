## 视觉说明

- **一句话主张**：筛选只改变光，不改变骨架——角色照片是页面上唯一的高饱和色彩来源。
- **透镜转化**：杂志的"刊号/目录/版权行/下期预告"全部映射为日历功能；编辑排印提供高级感，游戏立绘提供内容。
- **版式骨架**：报头带（刊名+游戏 tabs）→ 刊号带（巨型描边数字 08 与「八月」叠压）→ 双细线（杂志隔线）→ 目录区（7×6 发丝线网格）→ 版权行。焦点顺序：刊号数字 → 今日圆章 → 事件圆章群。
- **字体**：Bodoni Moda（拉丁/数字，高对比 didone）+ Noto Serif SC 900（中文标题/竖排名）+ Noto Sans SC 300/400（正文）。层级：92px 月名 / 430px 刊号 / 17px 资料值 / 10.5px 事件名 / 11.5px 字距拉开的微标签。
- **色彩分工**：中性色 = 暖炭底 `#15131a→#0d0c10`、象牙白文字、发丝线 9%；品牌金 `#c9a35f` 只用于"今天"与刊物仪式感；**阵营色只出现在圆章描边与选中态光晕**，来自项目现有 `affiliations*.ts` 色板（枫丹 `#4a8fc7/#86c8e8` 等），未新造颜色语义。
- **角色图片**：月视图中一律圆形圆章（头像 icon，52–64px，1.5px 阵营色环）；详情态才解锁全幅立绘（右侧 58% 摄影式裁切 + 左缘渐隐入纸）。小尺寸不用全身立绘裁切——脸部可读性优先。
- **月视图状态表达**：有事件 = 圆章 + 名条；多角色 = 叠章 + 「+N」虚线圈；今天 = 金色外环 + 绯红微光 + 角标「今」；空日 = 纯留白。
- **上下文切换**：选中枫丹后仅四处变化——刊号数字染水色渐变、kicker 变「FONTAINE SPECIAL」、命中格加水色衬底并放大圆章、非命中圆章灰阶退后（`grayscale .96 / opacity .38`）。骨架、栅格、报头完全不动。
- **材质与动效边界**：无玻璃/霓虹/粒子；唯一"光"是选中态径向晕。动效仅限入场淡现与 hover 圆章放大 1.06，移除后静态构图不变。
- **最可能失败处**：暗底低对比若被实现者削弱发丝线/次级文字对比，会显脏；巨型数字与网格的叠压需要克制的手感，实现时若描边过亮会变成干扰。

## 主要风险

1. 编辑感依赖排版精度，正式实现对字重/字距的还原要求高；
2. 暗色主题需通过文字对比度校验（象牙白 `#f2ede4` 对 `#15131a` 对比度约 12.9:1，安全）；
3. 远端图片源（nanoka/bilibili wiki）在生产环境应走本地缓存。
