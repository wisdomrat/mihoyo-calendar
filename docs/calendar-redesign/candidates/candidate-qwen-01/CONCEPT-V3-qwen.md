# 《角色志》CHARACTER CHRONICLE — V3 视觉概念

> 候选：candidate-qwen-01 · 创意透镜 07：时尚杂志与游戏主视觉的结合
> 概念板源文件：board01–04.html + shared.css（可重拍：shoot.sh）

## 方向名称

《角色志》：把每个月做成一期杂志，角色是封面人物，日历是本期目录。编辑式排版 × 摄影式裁切 × 游戏主视觉。

内部发散（四方向比较）：
1. 杂志封面式（最终）：月刊号 + 封面人物 + 目录日历。媒介：编辑排版/摄影裁切。风险：纸感滑向档案感（以现代无衬线、大留白与深色舞台页对冲）。
2. 收藏卡柜：暗舞台上排列角色卡。风险：卡牌手游 UI。
3. 世界观地图导航：地区为版块、日期为坐标。风险：纸质地图感、密度难控。
4. 舞台追光：聚光扫过月历。风险：静态不成立、赛博模板感。

## 四个审美问题

1. 前三秒：封面立绘 → 巨型「08」期号与封面标题 → 今天（22 日）绛红格。
2. 识别度：立绘是封面内容而非背景；刊头/期号/栏目构成杂志隐喻，四游真实角色名单即目录——不是 SaaS Dashboard。
3. 权重：角色内容 ≈45%，日期日历 ≈35%，游戏/阵营氛围 ≈20%（只做点染与专栏，不抢主体）。
4. 去动画去色后：刊头网格、细线、留白、衬线大字与无衬线小字的对比仍成立。

## 视觉说明

- 主张：每月一刊，每个生日都是一则栏目。
- 版式：刊头 92px → 封面带 400px（左期刊信息 / 中封面 / 右近期栏目）→ 目录日历 → 刊尾 bar。
- 字体：衬线（Georgia/宋体系）管名字、期号、日期；无衬线（雅黑）管标注；46–88px 大字对 10–11px 小字强对比。
- 色彩：纸 #f2efe9、墨 #17150f、主绛红 #7c1827（今天/封面/印章）；四游色仅作 7px 圆点与栏目点染；选中枫丹整页染青 #2c6069。
- 角色图：封面立绘摄影式裁切 + 底部压暗保文字；日历 22px 圆头像叠放；详情左缘立绘出血。
- 月视图状态：有事件=头像叠放+×n；今天=绛红实底反白；选中=墨色内描边+下划线；多角色=叠放+「+n」。
- 切换游戏/阵营：染色、专栏、封面题注、chips 改变；刊头、网格、字体、今天格稳定。
- 材质：仅 4.5% 噪点纸纹与立绘渐变压暗；无玻璃、无霓虹、无粒子。

主张 18/20 · 构图留白 20/25 · IP 表现力 17/20 · 一致性 13/15 · 差异与记忆点 8/10 · 工具可信 9/10 = **85**

## 风险

- 浅色纸面接近禁区「米白纸面」，靠封面带与编辑排版区分；若评审判为重复，应压暗封面带或改深色母版。
- 衬线栈跨平台不一致（Windows 落 SimSun），实现期需引入 webfont。
- 「谁上封面」需要产品规则（当月最近生日 / 用户收藏优先）。
